# 🎮 Quien Quiere Ser Millonario - Python

## 📌 Descripción

Aplicación desarrollada en Python utilizando Pygame que simula el juego "¿Quién quiere ser millonario?".

El proyecto incluye lógica de preguntas, sistema de vidas (comodines), temporizador y manejo de eventos.

---

## 🛠️ Tecnologías utilizadas

* Python
* Pygame

---

## ⚙️ Funcionalidades

* Sistema de preguntas con múltiples opciones
* Temporizador por pregunta
* Comodines (50/50, público, llamada)
* Interfaz gráfica con eventos de usuario

---

## ▶️ Cómo ejecutar

1. Clonar el repositorio
2. Instalar dependencias:

   ```bash
   pip install pygame
   ```
3. Ejecutar:

   ```bash
   python main.py
   ```

---

## 🎯 Objetivo del proyecto

Aplicar conceptos de programación como estructuras de datos, lógica de eventos y desarrollo de interfaces.
